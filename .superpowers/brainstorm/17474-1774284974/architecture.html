Flusso dati principale

GitHub Actions (ogni 15 min) → POST /api/ingest?secret=TOKEN → Ingestion Service → deduplica per hash → salva SourceItem + Event su Neon
Utente apre app → Next.js legge da Neon → UI aggiornata
Admin crea evento manuale → POST /api/admin/events → Neon → trigger notifica push (VAPID)
