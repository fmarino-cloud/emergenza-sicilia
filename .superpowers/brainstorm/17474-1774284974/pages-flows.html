Mappa del sito

🌐 AREA PUBBLICA
/ — Home "Situazione in tempo reale"
• Hero: stato attuale (N eventi attivi per categoria + livello generale)
• Lista eventi attivi (ordina: recente | severità | distanza)
• Box ultimi feed ufficiali
• Box editoriale in evidenza (da WP cache)
• Modulo rapido "Imposta alert"
/mappa — Mappa interattiva
• Leaflet full-screen con marker cluster
• Sidebar filtri: categoria, severità, data
• Popup marker → scheda evento rapida
• Link "Vedi evento completo"
/eventi/[id] — Pagina evento
• Header: titolo, chip categoria+severità, fonte+timestamp
• Mappa mini con pin
• Timeline aggiornamenti
• Segnalazioni verificate collegate
• Editoriali correlati (da WP cache)
• CTA: "Ricevi alert per questa area"
/fonti — Fonti ufficiali
• Lista fonti configurate con descrizione
• Per ciascuna: ultimi 5 item importati + link originale
• Badge "aggiornato X minuti fa"
/editoriale — Blog editoriale
• Griglia articoli da WP cache (filtri: tipo, categoria)
• Badge PREMIUM con paywall soft
• /editoriale/[slug] — articolo singolo (SEO + OG)
/segnala — Segnalazione lettori
• Form: testo + foto/video (Supabase storage) + posizione opt-in
• Progress "In verifica" post-invio
• Rate limit: max 3 invii/ora per IP
/alert — Preferenze alert · /premium — Pricing
• /alert: selettore categorie + provincia + attiva notifiche push
• /premium: pagina pricing freemium/premium (mock checkout)
🔐 AREA ADMIN (/admin/*)
/admin — Dashboard
• KPI: eventi attivi, segnalazioni in coda, ultimi feed
• Quick actions: crea evento, approva segnalazione
/admin/eventi — Gestione eventi
• Tabella eventi (filtri, search)
• Crea/modifica evento manuale
• Chiudi/archivia eventi
/admin/segnalazioni — Moderazione
• Queue segnalazioni NUOVO/IN_VERIFICA
• Approva / Rifiuta + motivazione
• Collega segnalazione a evento esistente
/admin/editoriali — Sync WP + paywall
• Lista articoli sincronizzati da WP
• Toggle paywall FREE/PREMIUM
• Toggle featured
• Force sync manuale
/admin/sponsor — Banner
• CRUD banner: posizione, immagine, link, date attività
• Preview posizione
/admin/alert — Simula push notification
• Seleziona evento → invia push a tutti i subscriber matching
• Log invii recenti
/admin/audit — Log azioni
• Tabella AuditLog con filtri per admin, azione, entità
